Also available: Synapse-1.4.0-x64.dmg for Intel (x64), not yet tested on Intel hardware. Builds are ad-hoc signed and not notarized. Synapse tells you when a new version is out; installing it is a quick manual swap.

Install it

  1. Open the downloaded .dmg and drag Synapse onto Applications.
  2. Open Synapse. The first time, macOS says it cannot verify the app, because builds are not notarized yet.
  3. Open System Settings → Privacy & Security and click Open Anyway. You only do this once.
  4. Choose Open folder as vault for an existing folder of notes, or Create new vault.

Updating: download the new version and replace the app in Applications. Your notes and preferences are not touched. More in the installation guide.
