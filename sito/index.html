Built around the link.

Everything in Synapse starts from one idea: notes are worth more when they point to each other. Pick a feature to see it in the app.

New in 1.4.0.

Tasks, related notes, export, version history, daily notes and templates all arrived with the 1.4.0 download. The release notes say what each published version has.

  • A report on your attachments

    One command lists attachments that are missing, and files no note links to or mentions. It only reports: nothing is deleted, so you decide what to clean up.

  • Open a folder, see it first

    Opening a folder that is not a vault yet shows a read-only summary first: links, attachments, syntax Synapse does not use. Cancel leaves the folder untouched.

  • Daily notes and templates

    Open today’s note in one command, step to the day before or after, and start notes from built-in or your own templates, with {{title}}, {{date}} and {{time}} filled in.

Questions, answered.

Is Synapse free?

Yes. Synapse is open source under the MIT licence, and the builds on GitHub Releases are free to download. There is no account and no subscription.

Can I open my Obsidian vault?

A vault is any folder of Markdown files, so you can open an existing one. Synapse writes only its own .synapse/ folder and never modifies .obsidian/. Obsidian community plugins are not supported.

Where are my notes stored?

Wherever you put the vault folder. Every note is a .md file you can open in any editor, sync however you like and back up with Time Machine. Preferences live separately, in ~/Library/Application Support/Synapse.

Why does macOS warn me the first time?

Builds are ad-hoc signed and not notarized yet, so macOS cannot verify them. Open System Settings → Privacy & Security and click Open Anyway, once.

Does it run on Intel Macs?

Since 1.3.0 there is an Intel (x64) build next to the Apple silicon one, both for macOS 13 Ventura or later. The Intel build has not been tested on Intel hardware yet, so please report any problem.

I read about tasks, related notes and export. Where are they?

They arrived with release 1.4.0, which is the download today. The release notes say what each published version has.

Does Synapse go online?

Only to check for a new version at launch (one request to GitHub, which you can switch off) and when a note asks it to, such as loading a remote image or opening a web link in your browser. No telemetry, no cloud sync.
