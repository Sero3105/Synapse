## What Synapse is

<CardGrid>
  <Card title="Plain files, no lock-in" icon="document">
    Every note is a `.md` file in a normal folder. Open it in any editor, sync it however you like, back it up with Time Machine.
  </Card>
  <Card title="Preferences that stay put" icon="setting">
    Theme, fonts, editor and hotkeys are global. Switching vaults never resets them; any setting can be overridden for one vault.
  </Card>
  <Card title="Links are the point" icon="puzzle">
    Wiki links to notes and headings, backlinks with context, unlinked mentions, nested tags and a live graph, global or local.
  </Card>
  <Card title="Private by design" icon="approve-check">
    No account, no telemetry, no cloud. Your notes never leave your Mac.
  </Card>
</CardGrid>

## Words used in these docs

- **Vault**: any folder of notes you open in Synapse. Subfolders are part of it.
- **Note**: a Markdown file (`.md`) inside a vault.
- **Wiki link**: a link written as `[[Note name]]`.
- **Global setting**: a preference stored with Synapse that applies to every vault.
- **Vault override**: a preference stored in one vault that replaces the global value there only.
